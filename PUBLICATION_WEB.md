# Publier WINDOWS 12 ULTIMATE sur Internet

La version web est composée de `index.html`, `web.css` et `web-app.js`. Elle fonctionne sur PC, téléphone et tablette avec un navigateur récent.

## Mise en ligne avec GitHub Pages

1. Connecte-toi à GitHub et crée un dépôt public, par exemple `windows-12-ultimate`.
2. Ajoute **uniquement** `index.html`, `web.css` et `web-app.js` à la racine du dépôt.
3. Dans le dépôt, ouvre **Settings → Pages**.
4. Sous **Build and deployment**, choisis **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`. Enregistre.
5. Attends la fin du déploiement. GitHub affichera une adresse du type `https://nom-utilisateur.github.io/windows-12-ultimate/`.
6. Ouvre cette adresse sur chacun de tes appareils et partage-la.
7. Sur un téléphone ou une tablette, utilise le menu du navigateur et choisis **Ajouter à l’écran d’accueil** si cette option est proposée.

Le dépôt public rendra ces trois fichiers visibles à tous. Ne publie pas de mot de passe ni d’autres informations privées.

## Limites de la version web

- Les profils, réglages, jeux et installations sont sauvegardés dans le navigateur **de chaque appareil**. Ils ne se synchronisent pas entre appareils.
- Les jeux, joueurs et publications Roblox/Play Store sont fictifs et locaux; aucun service Roblox ou Google n’est contacté.
- Le navigateur et le terminal intégrés sont des simulations. Le terminal n’exécute pas de commandes sur l’appareil.
- La version Python/Tkinter `app.py` reste une application de bureau distincte.
