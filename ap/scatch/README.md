# Assistant IA Scratch

## Démarrage

1. Installe une version récente de Node.js si nécessaire.
2. Crée une clé Gemini dans Google AI Studio : https://aistudio.google.com/apikey
3. Copie `.env.example` en `.env` et remplace la valeur par ta clé API. Ne partage pas ce fichier.
4. Double-clique sur `start-ai.cmd`.
5. Ouvre `http://127.0.0.1:3000` dans ton navigateur.
6. Ouvre un projet, écris ta demande dans « Assistant de programmation », puis clique sur « Demander à l’IA ».

La clé reste dans le fichier local `.env` et le navigateur ne la reçoit jamais. Les appels au modèle peuvent être soumis aux limites ou aux conditions du compte Gemini.
