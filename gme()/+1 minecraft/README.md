# +1 KeyQuest

Un petit jeu incrémental au clavier : gagne un point à chaque touche pressée ou en cliquant sur **Gagner +1**, monte de niveau, explore trois mondes et collectionne des skins 3D dessinés en CSS.

## Lancer le jeu

1. Installez Node.js 18 ou plus récent.
2. Dans PowerShell, placez-vous dans le dossier du jeu :

   ```powershell
   cd "C:\Users\Labtop\Desktop\crée"
   ```

3. Lancez le serveur :

   ```powershell
   node server.js
   ```

4. Ouvrez `http://127.0.0.1:4173` dans votre navigateur.

La progression est sauvegardée localement dans le navigateur. La Prairie paisible est disponible dès le départ ; le Désert doré se débloque à 50 points et le monde Néon nocturne à 150 points. Steve est le skin de départ ; les skins Creeper, Enderman et Astronaute se débloquent respectivement à 20, 60 et 120 points.
